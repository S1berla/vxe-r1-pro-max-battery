# VXE R1 Pro Max Battery v0.1.0

首个可测试版本。

## 功能

- 通过 `VID_3554 / PID_F58A` 2.4G 接收器读取 VXE Dragonfly R1 Pro Max 电量
- 托盘图标使用鼠标轮廓，绿色填充比例表示电量
- 悬停显示精确电量、充电状态和电压
- 双击打开电池详情窗口
- 默认开机启动，可通过右键菜单关闭
- 设备休眠或 HID 被占用时保留上次有效值
- 单实例运行
- Per-Monitor V2 DPI 感知
- 附带控制台读取工具和 JSON 输出

## 使用要求

- Windows 10/11 x64
- .NET Framework 4.8
- 2.4G 接收器保持插入
- 建议退出 ATK HUB 客户端

## 已知行为

- 鼠标休眠时读取可能超时，移动鼠标唤醒后会恢复。
- ATK HUB 或另一个 HID 读取程序可能占用输入报告。
- 第一版不发送低电量通知。
